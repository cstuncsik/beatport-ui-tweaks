Privacy policy

Last updated: October 24, 2026

Beatport UI Tweaks is a browser extension that adds small tweaks to beatport.com. It has no server of its own, no analytics and no ads. Nothing it handles is sent to the developer, and nothing is sold or shared.

What it keeps, and where

  • Your feature switches, and the last played track of each Beatport list: the track's ID under the list's genre or artist and type, for example "drum-bass, tracks". They are kept in the extension's storage in Chrome (chrome.storage.sync). If you use Chrome sync, Chrome syncs them between your devices through your Google account.
  • The playlists you added tracks to, latest first, so they lead the "add to playlist" dialog: their IDs and the playlist details Beatport sent for them, such as the name and the track count. They are kept in beatport.com's local storage in your browser.
  • For the update notices: the last version whose notes you saw and, while one is out, the number of a newer version. They are kept in the extension's storage on this device (chrome.storage.local).

What it reads on beatport.com

To do its job the extension reads parts of the Beatport pages you open: the track lists (titles, track IDs, keys), the player and the "add to playlist" dialog with your playlist names. It notices your clicks on play buttons and the A and Z keys, and it watches Beatport's own playlist requests in the page to learn which playlist you added tracks to. All of this stays in your browser.

Requests it makes

  • Beatport: the "Last played" button asks Beatport's catalog API (api.beatport.com) where the remembered track is now. It uses the access token the Beatport page itself uses: your session token, read from Beatport's own session endpoint, when you are logged in, otherwise the anonymous token Beatport puts in the page. The token is used only for these requests to Beatport and is not stored.
  • GitHub: copies installed from a GitHub release zip, which the Chrome Web Store doesn't update, ask GitHub's API (api.github.com) once a day for the version number of the latest release. The request carries no data about you; like any web request, it shows your IP address to GitHub. Copies from the Chrome Web Store don't make this request.

What it doesn't do

The extension doesn't sell or transfer your data, doesn't use it for anything but the features above, and doesn't track you, show ads or build profiles.

Removing the data

Uninstalling the extension removes its storage. The playlist history stays in beatport.com's local storage until you clear the site's data in your browser.

Changes and contact

Changes to this policy are published on this page. Questions: open an issue on GitHub.
